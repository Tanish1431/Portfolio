# Tanish Khandelwal — Portfolio

A clean, modern, and responsive personal portfolio built with React, Vite, and Tailwind CSS.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Customization

Edit `src/portfolio.js` to update personal information, experience, education, skills, projects, and achievements.

Upload your resume as `src/containers/greeting/resume.pdf`.

## Tech Stack

- **React 18** — UI framework
- **Vite 5** — Build tool
- **Tailwind CSS 3** — Utility-first styling
- **SCSS** — Component styles
- **Framer Motion** — Animations
- **Lucide React** — Icons
- **Lottie React** — Animated illustrations

## Deployment

Build the production bundle:

```bash
npm run build
```

The output is in the `build/` directory, ready to deploy to any static hosting provider (Netlify, Vercel, GitHub Pages, etc.).
